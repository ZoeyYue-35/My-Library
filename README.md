# My Library

**Your cloud-based career knowledge library — resumes, experience stories, and interview preparation in one place.**

## Open My Library

**Live app: https://my-library-0lcr.onrender.com/**

> **No Fork, clone, download, or local installation is required to use My Library.** Just open the link above in your browser, create an account or sign in, and start using your own workspace. This GitHub repository contains the source code; it is not the app's sign-in page.

My Library is a cloud-hosted application for organizing career materials and preparing for interviews. Each new user starts with an empty workspace and can add their own resumes, documents, role tracks, and interview stories.

## Getting started

1. Open **https://my-library-0lcr.onrender.com/** in your browser.
2. Create an account or sign in.
3. Follow the optional first-run quick tour.
4. Create a role track in **Resume Studio** and upload your materials.
5. Explore **Knowledge Library**, **STAR Story Builder**, and **Mock Interview**.

**Optional AI setup:** To use the AI-powered Story Builder and Mock Interview features, go to **Settings → Your OpenAI connection** and connect your own OpenAI Platform API key. Other core library and resume-management features do not require an OpenAI API key. API usage may incur charges from OpenAI.
